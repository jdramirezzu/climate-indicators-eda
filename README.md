# Climate Change Indicators — Exploratory Analysis

Univariate exploratory data analysis of global climate change indicators, built as coursework for the Master's in Applied AI.

## Contents

| File | Description |
|---|---|
| `Cuaderno_de_Análisis_Univariado.ipynb` | Jupyter notebook with the univariate analysis (in Spanish) |
| `climate_change_indicators.csv` | Source dataset with global temperature change indicators |
| `temperatura_global.png` | Global temperature trend chart produced by the analysis |

## Run it

```bash
pip install pandas matplotlib jupyter
jupyter notebook Cuaderno_de_Análisis_Univariado.ipynb
```
